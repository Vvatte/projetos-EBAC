# Curso Java - EBAC

Este repositorio reune todos os projetos, exercicios e atividades desenvolvidos durante o curso de Back-end Java da EBAC.

## Estrutura

- **/atividades** - Exercicios realizados ao longo do curso.
- **/projetos** - Projetos maiores desenvolvidos durante o curso.

## Sobre

O objetivo deste repositorio e documentar minha jornada de aprendizado em Java, incluindo desde os conceitos basicos ate topicos mais avancados de desenvolvimento back-end, como APIs REST, orientacao a objetos e Spring Boot.

## Tecnologias

- Java
- Git / GitHub
